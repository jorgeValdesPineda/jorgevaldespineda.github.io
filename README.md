# Portfolio de Jorge L. Valdés

Sitio estático personal en un único archivo (`index.html`), adaptable a móvil e imprimible. No requiere servidor ni dependencias para previsualizarlo: abre `index.html` en un navegador.

## Publicar gratis con GitHub Pages

1. Crea un repositorio público llamado `Jorgito9707.github.io` en GitHub.
2. Sube `index.html` a la raíz del repositorio.
3. En **Settings → Pages**, selecciona la rama principal y la carpeta raíz como origen.
4. GitHub publicará el sitio en `https://Jorgito9707.github.io`.

Puedes usar la dirección gratuita `github.io`; un dominio propio es opcional. Antes de publicar, comprueba el enlace de LinkedIn en la página.
